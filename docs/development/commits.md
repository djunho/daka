# Commit Convention


**Format:** `TYPE/commit-scope: description.`


---

# Commit Types

| Type | Usage |
|-|-|
| FEAT | New feature |
| FIX | Bug fix |
| DOCS | Documentation |
| STYLE | Formatting |
| REFACTOR | Code improvement |
| TEST | Tests |
| CHORE | Maintenance |

---

# Examples


- `FEAT/user-autentication: add login page.`
- `FIX/console-warning: fix all console warnings.`
- `DOCS: added database decision to ADR.`
