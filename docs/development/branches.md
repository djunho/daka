# Branch Strategy

## Main Branch

Name: `main`


Purpose:

- Contains the `production-ready` code. This is the website version that is available to the end-user.

---

## Development Branch

Name: `dev`


Purpose:

- Serves as the main staging area for the `next release`. It collects all the new features, bug fixes, and experiments that developers are working on.

---

# All Branche types

| Type | Usage |
|-|-|
| FEAT | New feature |
| FIX | Bug fix |
| DOCS | Documentation |
| STYLE | Formatting |
| REFACTOR | Code improvement |
| TEST | Tests |
| CHORE | Maintenance |

---

# Branche Examples

### Feature Branchs:

Naming convention: `FEAT/short-feature-name`


Examples:


- `FEAT/user-authentication`
- `FEAT/profile-picture`

### Bug Fix Branches

Naming convention: `FIX/bug-to-fix`


Examples:


- `FIX/login-error`
- `FIX/console-warnings`
